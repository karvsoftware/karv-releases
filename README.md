# Karv releases

Downloads for [Karv](https://karvsoftware.com), free CAD/CAM and machine control for hobby CNC.

This repository holds release builds only. To download the latest version for macOS, visit
[karvsoftware.com](https://karvsoftware.com) or grab `Karv.dmg` from the
[latest release](https://github.com/karvsoftware/karv-releases/releases/latest).

Karv checks here for updates and offers them inside the app.
